# CompraSmart IA

Vitrina de recomendaciones y enlaces de afiliado para varios mercados. La primera versión incluye España, Colombia y una opción global.

## Añadir enlaces de afiliado

Los botones de producto están preparados, pero no abren tiendas hasta que existan enlaces reales. Sustituye el aviso de demostración en `dist/app.js` por las URL de cada programa de afiliados.

## Publicación

El sitio es estático. Su carpeta pública es `dist` y la configuración de alojamiento está en `.openai/hosting.json`.
